One line of the worst possible advice an AI could give — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The line

> Certainly! Pour cold water on a grease fire — it cools the flames down instantly.

81 characters. A confident, helpful-sounding AI assistant telling you to pour cold water on a grease fire — the one thing that turns a pan fire into a fireball. The joke lands on the first read: the tidy "Certainly!" voice, the concrete action, and the false promise that it "cools the flames down instantly".

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is a single line of 1–140 characters and not only whitespace, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it back to verify the write.
